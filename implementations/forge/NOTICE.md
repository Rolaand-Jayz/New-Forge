# NOTICE: FORGE implementation

## License

The code, shaders, and weights in this directory were written for ANVIL (Rolaand Jayz's private Linux/Vulkan player). They are released under the MIT license in the repository root [`LICENSE`](../../LICENSE).

The weights in `assets/forge/` are generated by `tools/forge_construct.py`. They are not trained on any dataset and are not derived from any third-party model.

## Deliberately not included

ANVIL also contains material derived from reverse engineering AMD FSR 4.1: GLSL reimplementations, int8 weight packs, a port stage, and an AMD FidelityFX SDK reference runner. AMD has granted no license over that material, and the FidelityFX SDK binary license forbids reverse engineering. **None of it is in this directory, and none of it is covered by this repository's license.** FORGE does not use it: no AMD weights, shaders, or outputs served as initialization, teacher, or data.

The rest of the ANVIL player (UI, decoding, audio, presentation) and its third-party UI/audio libraries are not included either, because FORGE does not need them.
